# Examples

Walkthroughs of real sessions — every image here was rendered by Claude
through the MCP tools against a live Blender instance (4.3 for 01–03,
4.5 LTS headless for 04).

| Example | What it shows |
|---|---|
| [01 – Visual iteration](01-visual-iteration.md) | The render–critique loop: Claude fixes its own bad lighting by looking at drafts |
| [02 – Product shot](02-product-shot.md) | Modifiers, three-point lighting, `blender_frame_camera`, draft→final workflow |
| [03 – Turntable](03-turntable.md) | Animation rig via parenting, `blender_render_animation` with inline preview stills |
| [04 – Review & background jobs](04-review-and-jobs.md) | Execute diffs, a multi-view contact sheet catching a bug the hero angle hides, background render jobs |

Each example has a matching project skill you can invoke directly in this
repo: `/blender-iterate`, `/blender-studio-shot`, `/blender-turntable`.
